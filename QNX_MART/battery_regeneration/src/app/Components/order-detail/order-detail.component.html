Return Policies

Return Product – Terms & Conditions

Please read the following terms and conditions carefully before submitting a return request.

1. Return Eligibility

Products can be returned only if they are eligible for return and the request is raised within the specified return period.

2. Product Condition

The product must be returned in its original condition, along with the original packaging, accessories, tags, manuals, and invoice, wherever applicable.

3. Mandatory Unboxing Video Mandatory

A continuous, unedited unboxing video is mandatory for all return claims. The video must clearly show the sealed package, shipping label, complete unboxing process, product, and any damage, defect, or missing item.

4. Damaged / Wrong / Defective Product

Customers must report damaged, defective, wrong, or missing products within the applicable return period and provide the required unboxing video as proof.

5. Verification

All return requests are subject to verification. QNX MART may reject a return if the product does not meet the return conditions or sufficient proof is not provided.

6. Non-Returnable Products

Products marked as Non-Returnable or products damaged, used, modified, or misused by the customer may not be eligible for return.

7. Return Pickup

Once the return is approved, the product must be properly packed and made available for pickup as instructed.

8. Refund / Replacement

After successful verification of the returned product, an eligible refund or replacement will be processed according to the applicable product policy.

Important: Customers are advised to keep the unboxing video safely until the return period has expired and the return request, if any, has been completely resolved.
